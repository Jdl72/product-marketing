# Competitor Map

## Named Competitors

- `Pacvue`:
  - `Variants / aliases`: "Pack roo" (Fireflies mishear), "PackView" (buyer confusion with free AMC tool — resolve from context)
  - `Category`: Retail media management platform — rules-based, 4 AI levers (vs. Xnurta's 11), 100+ retailer coverage
  - `Notes`: Primary displacement target, especially in international markets (China, Europe). Ownership uncertainty from Assembly's sale attempts has led to cost-cutting and slowed AI roadmap. Key weaknesses: slow platform load times, static non-interoperable AI levers, keyword harvesting lacks depth, poor CSM support, no placement-level AI optimization, budget optimization is a black box. Where Pacvue wins: broader retailer coverage (100+), stronger rules-based tooling for teams wanting hands-on control, strong agency relationships (Channel Key, DEPT, Big 6 agencies). Term-normalization note: if a Fireflies transcript reads "Pack roo" in a context clearly referencing retail media SaaS, normalize to Pacvue.

- `Intentwise`:
  - `Variants / aliases`: None confirmed
  - `Category`: Commerce observability platform — recommendation-based AI (not autonomous), enterprise data infrastructure focus
  - `Notes`: Assigns 1 of 20 algorithms per account based on CPC and revenue — inflexible. 24-hour recommendation cycle requires manual implementation. AI Optimizer pauses 3 days after any manual intervention. Where Intentwise wins: Snowflake, Redshift, SQL Server, Power BI, Tableau, Looker Studio integrations; natural language querying via Wizi AI ("Show me campaigns with highest ACOS"); SOC 2 Type 2, ISO 27001, GDPR certifications; educational resources and AMC Learning Hub. Code "Intentwise displacement" as buying trigger when buyer cites frustration with 24-hour lag or manual implementation requirement.

- `Skai`:
  - `Variants / aliases`: Kenshoo
  - `Category`: Omnichannel advertising platform — search, social, and retail media (retail media bolted on, not native)
  - `Notes`: Built as search and social platform first; retail media is an add-on, not a core capability. Rules run on schedules, not continuously. 20+ years in market with strong enterprise brand clients (Amazon, Microsoft, Apple) and large agency relationships (Havas, OMD, GroupM, Wavemaker). Where Skai wins: genuine omnichannel activation (search + social + retail), flat quarterly pricing ($60K–$600K+/yr by spend), deep enterprise relationships. Where Xnurta wins: retail-media native architecture, 11 AI levers vs. 4-5, continuous optimization vs. schedule-based rules, faster innovation velocity dedicated to retail media. Displacement message: "Depth vs. breadth" — a mile wide and an inch deep.

- `Perpetua`:
  - `Variants / aliases`: None confirmed
  - `Category`: SMB retail media bidding platform (simplicity-first, "goal" structure) — part of Flywheel, owned by Omnicom
  - `Notes`: Charges only on managed ad spend (not total), making it low-barrier for SMBs ($50K+ spend sweet spot). No rules-based optimization. "One size fits all" AI with no toggle control — algorithm cannot be turned on/off by entity. Keyword stuffing risk (hundreds of targets in single campaigns). No budget dayparting. Campaign takeover forces relaunching campaigns. Where Perpetua wins: simplest setup, Omnicom DSP CPM discounts (5% platform fee), hourly share-of-voice visibility, AMC audiences built into DSP flow, bid dayparting algorithm by day of week. Omnicom parent relationship is a meaningful advantage for large agency DSP buyers. Target Perpetua accounts that are scaling beyond simple bid automation.

## Status Quo Alternatives

- `PackView AMC`:
  - `Type`: Free AMC analytics tool (not a direct software competitor)
  - `Notes`: Ejam transcript names this explicitly as justification for resisting Xnurta's AMC fee ("not paying anything with Pack roo"). This alias overlaps with the Pacvue mishear — always resolve from context. When buyer mentions PackView in an AMC fee objection, they mean this free tool, not Pacvue.

- `Amazon Ads native console`:
  - `Type`: Free default platform alternative
  - `Notes`: Seller Central, Vendor Central, and the native Amazon ad console. Most common status quo — buyers default here when evaluating cost of switching. AMC is part of this ecosystem.

- `Manual agency management`:
  - `Type`: Service substitute
  - `Notes`: Buyer is relying on an agency or internal headcount instead of a managed service platform. "The same guy is like managing like multiple accounts" (Ejam transcript) is the canonical objection framing — buyer uses this to argue managed service fees are disproportionate to the labor involved.

- `Internal headcount`:
  - `Type`: Build vs. buy alternative
  - `Notes`: Hiring an internal ecommerce or media buyer instead of paying for managed service. Ejam transcript cites this as a considered alternative. Use to code build-vs-buy objections.
