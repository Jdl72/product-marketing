# Example Client Workspace

This folder demonstrates the minimum contract for a client workspace that consumes the Product Marketing system.

Use it as a starting point for a new consulting client.

## What this example is for

- showing the required workspace shape
- showing the minimum config pack
- showing where evidence, records, syntheses, briefs, and decisions should live

## What this example is not

- a production client workspace
- a place for real client IP
- a substitute for the core schemas and jobs

## Recommended use

1. Copy the `generic-example/` folder into a client-specific workspace.
2. Rename it for the client.
3. Fill in the config pack before coding or synthesizing new calls.
4. Use the core repo jobs and schemas to populate records and syntheses.
5. Run the client-workspace evaluation artifact to confirm the workspace still satisfies the reusable contract.
