# Conversation Examples

This folder is for the first manual examples of the discovery workflow.

## First example set

1. `raw-source`
   One real conversation transcript, note set, or feedback thread
2. `conversation-record`
   The structured parse of that source
3. `review-notes`
   What was weak, over-interpreted, or missing
4. `conversation-synthesis`
   A grounded synthesis across multiple parsed records with record-level citations

## Rules

- Redact sensitive information before committing examples.
- Keep source provenance visible.
- Preserve exact customer language where safe.
- Add review notes after each manual run so schema and rubric gaps become obvious.
- Keep raw transcript exports local unless they have been explicitly redacted for sharing.
