# PR-FAQ Template

Portable markdown module for workbook artifact `3.2 PR-FAQ Template`.

## Purpose

Create the central governance document for the launch.

## Core rule

Treat this as a co-authored upstream alignment artifact, not a late-stage copy document.

## Non-negotiables

- PM and PMM co-author it.
- If they cannot agree on headline, customer, and problem, the launch is not ready.
- Update it weekly during discovery.
- Lock it at narrative lock.
- Flag every claim that outruns proof or current product reality.

## Required sections

- `Headline`
- `Subhead`
- `Customer Problem`
- `Why Now`
- `Why This Wins`
- `Press Release Narrative`
- `External FAQ`
- `Internal FAQ`
- `Open Questions`
- `Next Required Artifact`

## Instructions

1. Pull from `START HERE`, `Positioning Canvas`, and `Customer Interview`.
2. Write the headline only if PM and PMM can agree on the customer and problem.
3. Update weekly during discovery until `Narrative Lock`.
4. Flag claims that outrun current proof or roadmap reality.
5. Replace invented customer language with real customer language wherever possible.

## Handoff

Feeds:

- `Stage Gate Architecture`
- `Narrative Lock`
- `Narrative Skeletons` if later added
