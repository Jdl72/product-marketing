# Segment Playbooks

Portable markdown module for workbook artifact `4.2 Segment Playbooks`.

## Purpose

Adapt the core narrative into segment-specific motions without blending distinct buyers.

## Non-negotiables

- One segment block per real segment.
- If you have not interviewed a segment, mark the playbook speculative.
- Tailor message, proof, objection, and sales motion together.
- Do not blend segments that need different positioning tracks.

## Required fields per segment

- `Job Title / Persona`
- `Company Profile`
- `Primary Pain`
- `Secondary Pain`
- `Buying Trigger`
- `Key Message`
- `Proof Point`
- `Objection to Expect`
- `Content Assets Needed`
- `Sales Motion`

## Inputs

- `Customer Interview`
- `Positioning Canvas`
- `Attack Matrix`

## Handoff

Feeds:

- `Battle Cards`
- `Bar Test`
- `ROI Calculator`
