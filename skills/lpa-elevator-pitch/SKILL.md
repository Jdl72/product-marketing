# Elevator Pitch

Portable markdown module for workbook artifact `3.3 Elevator Pitch`.

## Purpose

Convert the positioning into compact verbal forms that can be tested and reused.

## Non-negotiables

- Pull the opening hook from validated customer pain.
- Create all three lengths, not just one.
- Build persona variations only after the core pitch is stable.
- Keep the CTA aligned to buyer stage and segment motion.

## Output

- `10-second version`
- `30-second version`
- `60-second version`
- `Persona variations`
- `CTA`
- `Next Required Artifact`

## Inputs

- `Positioning Canvas`
- `Customer Interview`

## Handoff

Feeds:

- `Bar Test`
- `Battle Cards`
- `Segment Playbooks`
