# Attack Matrix

Portable markdown module for workbook artifact `3.4 Attack Matrix`.

## Purpose

Map the real alternatives buyers use today and define how the launch attacks each one.

## Section order

1. `Status Quo Alternative`
2. `How Buyers Do It Today`
3. `Pain / Cost of Status Quo`
4. `How We Beat This`
5. `Proof Point / Evidence`
6. `COMMON OBJECTIONS & RESPONSES`

## Non-negotiables

- Map the status quo honestly.
- Use customer-described workflows and pain, not guessed alternatives.
- Tie responses to proof whenever possible.
- Quote objections as they are actually heard in interviews.

## Output

- `Status Quo Alternative`
- `How Buyers Do It Today`
- `Pain / Cost of Status Quo`
- `How We Beat This`
