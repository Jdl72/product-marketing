# Bar Test

Portable markdown module for workbook artifact `4.1 Bar Test`.

## Purpose

Stress-test message clarity before external amplification.

## Core rule

If someone cannot explain the message to a friend at a bar, it is not ready.

## Non-negotiables

- Test each message with 3-5 people outside the team.
- Record the exact wording tested.
- Use tester verbatim feedback, not post-rationalized summaries.
- Re-test failing messages until pass rate reaches at least 80%.

## Inputs

- `Elevator Pitch`
- `Positioning Canvas`
- `Segment Playbooks`

## Output

- `Pass / Fail Scores`
- `Tester Verbatim`
- `Suggested Rewordings`
- `Clarity Risks`
- `Next Required Artifact`

## Best practices

- Test pitch versions verbatim before paraphrasing them.
- Test differentiators and value props separately.
- Use the same personas interviewed earlier as testers when possible.
