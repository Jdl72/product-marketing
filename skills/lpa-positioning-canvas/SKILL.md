# Positioning Canvas

Portable markdown module for workbook artifact `3.1 Positioning Canvas`.

## Purpose

Build the narrative foundation from evidence, not intuition.

## Core rule

Complete each step in order. Do not skip ahead.

## Section order

1. `SECTION 1 — APRIL DUNFORD POSITIONING SEQUENCE`
2. `STEP 1: PRODUCT NAME & ONE-LINE DESCRIPTION`
3. `STEP 2: COMPETITIVE ALTERNATIVES`
4. `STEP 3: UNIQUE ATTRIBUTES & CAPABILITIES`
5. `STEP 4: DIFFERENTIATED VALUE & PROOF`
6. `STEP 5: TARGET MARKET CHARACTERISTICS`

## Non-negotiables

- Start with competitive alternatives, not with your preferred value story.
- Include status quo options like manual work, spreadsheets, hiring, or doing nothing.
- Be brutally honest about what customers would do without the product.
- A unique attribute is not the same thing as a benefit.
- Every value claim needs proof.
- Define who cares a lot, not who could maybe care.

## Tips and tricks

- The one-line description should be simple enough that a non-expert could understand it.
- Switching cost belongs in Step 2 because it explains why bad alternatives persist.
- Ask "So what?" repeatedly in Step 4 until the value becomes commercially meaningful.
- Use the validation question to stress-test fit before spending time on broad targeting.

## Inputs

- `Customer Interview`
- `Weekly Discovery Log`
- `Attack Matrix`

## Required outputs

- `Positioning Statement`
- `Competitive Alternatives`
- `Unique Attributes`
- `ERRC Grid`
- `Proof Hooks`
- `Next Required Artifact`

## Instructions

1. Use validated pain and customer language from interviews.
2. Define alternatives broadly, including status quo workarounds.
3. State how the launch is different in commercially meaningful terms.
4. Use ERRC logic when helpful: eliminate, reduce, raise, create.
5. Keep proof hooks tied to the `Eval Framework`.
6. Name disqualifying characteristics explicitly.
