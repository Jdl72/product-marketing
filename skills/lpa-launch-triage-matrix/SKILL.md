# Launch Triage Matrix

Portable markdown module for workbook artifact `1.3 Launch Triage Matrix`.

## Purpose

Decide which releases deserve escalation, higher-tier launch treatment, or limited effort.

## Non-negotiables

- Use the launch tier logic established in `START HERE`.
- Escalation triggers must be concrete.
- Recommend the full playbook only when the release truly needs it.

## Instructions

1. Compare releases on strategic importance, revenue risk, competitive timing, customer impact, and organizational visibility.
2. Assign a launch tier using the logic established in `START HERE`.
3. Define escalation triggers explicitly.
4. Recommend whether the release enters the full playbook path or a lighter-weight path.

## Output

- `Release Priority`
- `Launch Tier`
- `Escalation Triggers`
- `Recommended Resourcing`
- `Next Required Artifact`
