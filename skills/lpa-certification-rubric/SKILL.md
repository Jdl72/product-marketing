# Certification Rubric

Portable markdown module for workbook artifact `5.3 Certification Rubric`.

## Purpose

Apply the final messaging quality gate before `Lightning Strike`.

## Non-negotiables

- Score every dimension.
- No dimension can be below 3.
- Average score must be at least 3.0.
- Evidence must reference the upstream tabs named in the workbook.
- Treat this as the final quality gate before external use.

## Scored dimensions

- `Clarity`
- `Differentiation`
- `Customer-Centricity`
- `Proof / Evidence`
- `Consistency`
- `Emotional Resonance`
- `Competitive Awareness`
- `Actionability`

## Rule

Certification requires:

- average score >= 3.0
- zero dimensions below 3

## Inputs

- `Bar Test`
- `Battle Cards`
- `Customer Interview`
- `Eval Framework`
- `Impact Protocol`

## Output

- `Dimension Scores`
- `Evidence / Notes`
- `Average Score`
- `Dimensions Below 3`
- `Certification Status`
- `Next Required Artifact`
