# ROI Calculator

Portable markdown module for workbook artifact `4.4 ROI Calculator`.

## Purpose

Translate validated value levers into a conservative financial case.

## Section order

1. `Prospect Profile`
2. `Value Levers — Define With Prospect`
3. `Financial Translation — Convert Levers to Dollars`
4. `Investment & ROI Summary`

## Non-negotiables

- Configure the primary metric with the prospect during discovery.
- Use the metric the customer actually tracks.
- Use numbers from interviews and evals, not guesses.
- Use conservative estimates.
- Do not use unverified improvement numbers.

- `Prospect Profile`
